# LeafBase has moved to BysonDB

> ⚠️ **This repository is no longer maintained.**
>
> **LeafBase has been renamed to BysonDB.** All development, releases, and issues now
> live at the new repository:
>
> ### 👉 https://github.com/vutranHS/byson

---

## What happened?

The project formerly known as **LeafBase** is now **BysonDB** — the same free,
open-source MongoDB GUI, just under a new name. Nothing about the app's features or
functionality changed; only the name did.

## For existing users

Because the app's identity changed, **BysonDB is treated as a new application** and
will not auto-update from an old LeafBase install. To move over:

1. Download the latest **BysonDB** from the
   [new Releases page](https://github.com/vutranHS/byson/releases).
2. (Optional) Export your query tabs from LeafBase via **Workspaces → Export**, then
   import them into BysonDB.

See the full migration notes in the
[BysonDB v1.1.5 release](https://github.com/vutranHS/byson/releases/tag/v1.1.5).
